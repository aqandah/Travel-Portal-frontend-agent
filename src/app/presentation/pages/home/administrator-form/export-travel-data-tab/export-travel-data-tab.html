Date Range Parameters
Export Guide

Instructions for exporting travel data:

  • Select the From Date to specify the start of the export period
  • Select the To Date to specify the end of the export period
  • The exported data will include all travel insurance records within the selected date range
  • Data will be exported in CSV format so that it can be easily analyzed and processed
Note

Large date ranges may take longer to process. For optimal performance, consider exporting data in smaller increments.
